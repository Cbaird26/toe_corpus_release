# Glossary

Normalize terminology across the corpus. Use only these terms as specified.

| Term | Definition |
|------|------------|
| **complete** | Do not use for the framework; prefer "specification-level closed" or "empirical closure pending" |
| **closed** | Specification-level: formal domains (A–H) are defined. Not the same as empirical closure. |
| **solved** | Formal/specification closure under the A–H map. |
| **referee-proof** | Survives hostile peer review; requires hardening tasks to be finished. |
| **100%** | Do not use; corpus explicitly says empirical closure is separate. |
| **specification-level closed** | All formal domains (variational, dynamical, measurement, ethics, no-signaling, relativistic, teleology, computability) are specified. |
| **empirical closure** | Bounds, preregistered tests, independent replication. |
| **hardening** | Operational definitions, proofs, parameter bounds, flagship falsifier. |
| **Φc** | Consciousness field. |
| **E** | Ethical field. |
| **teleology** | Measure tilt; ethics-weighted Born rule. |
