# Claims Taxonomy

Use only these four claim types when classifying.

| Type | Meaning |
|------|---------|
| **proved** | Mathematically or empirically verified |
| **specified** | Formally defined in the framework; not yet proved |
| **conjectural** | Hypothetical; open |
| **experimental** | Requires or awaits experiment |

## Rules

- Do not invent new categories.
- Downgrade overclaims: if a claim says "proved" but canonical status says "specified," use "specified."
- When in doubt, use "conjectural" or "experimental."
